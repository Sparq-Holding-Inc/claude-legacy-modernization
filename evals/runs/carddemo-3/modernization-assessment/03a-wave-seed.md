# 03a Wave seed

Generated by `render.py` from `graph.json`. This is a first cut of the waves from facts alone. It does not judge risk. Every entry point is put in one family by four tests in order: it touches DB2, IMS or MQ; it writes a dataset a different entry point also uses; it is online or batch; it runs an application program or none. A unit used by several entry points moves with the earliest family that uses it. A scheduler job moves with the last family among the jobs it runs. A call cycle always moves whole. A family is then cut into groups. Two entry points in it are bound together when both write the same dataset or run the same application program. Bound entry points share a wave (coupled). The rest form one independent wave, listed first. A coupled wave can still be too big to ship alone.
